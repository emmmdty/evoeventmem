## 1. Motivation

vector_rag (EM=0.56) beats event memory (EM=0.48) because it retrieves raw text. Event memory loses because extraction paraphrases raw text into summaries.

**Goal**: Build a method that **beats vector_rag** by combining raw text precision with event memory structure.

## 3. The Actual Gap

The existing system has raw text (`EvidenceRef.quote`) but **doesn't index it for retrieval**. The dense retrieval embeds `MemoryRecord.content` (paraphrased summary), not the raw text.

**EAMG's contribution**: Index raw text at Level 0 for dense retrieval, alongside event frames at Level 1. This is NOT about new extraction or new storage — it's about **what gets embedded and retrieved**.

## 4. MVP: Evidence-Anchored Vector RAG (4-5 days)

### 4.1 What the MVP Does

1. **Modified extraction prompt**: Ensure `evidence.quote` contains EXACT complete sentences (not abbreviated)
2. **Level 0 + Level 1 in one repository**: Raw turn chunks + event frames, both indexed for dense retrieval
3. **Existing QEMR retrieval**: Dense/temporal/graph signals work across all memories
4. **No Level 2 (session summaries)**: Deferred
5. **No new query classifier**: Reuse existing router

### 4.3 What the MVP Proves

- Detail queries: EAMG = vector_rag (both retrieve raw text)
- Temporal queries: EAMG > vector_rag (event frames have temporal structure)
- Evidence provenance: 100%
- Token cost: Within 1.5x (budget cap + deduplication)

### 4.4 What the MVP Does NOT Prove

- Cross-session reasoning superiority (needs Level 2)
- Adaptive routing superiority (needs query classifier extension)
- Full 50q benchmark comparison (needs parallel runner)

## 5. Token Cost Fix

**Problem**: Level 0 raw chunks duplicate text in both `content` and `evidence_ref.quote`.

**Fix**: Skip `source:` quote line for Level 0 items where `content == quote`.

Saves ~50% of Level 0 tokens, making 1.5x target comfortably achievable.

## 6. Research Positioning

**Not a new retrieval paradigm.** It is:

1. A **practical response** to a documented negative result
2. The first to show that **evidence-constrained event memory** needs raw-text indexing to match vector RAG
3. A quantification of the extraction-abstraction gap

**Paper title**: "Why Event Memory Underperforms Raw RAG: A Negative Result and Evidence-Anchored Remediation"

**Strongest contribution**: The ETEC SUPERSEDE trade-off finding (helps knowledge-update, hurts temporal-reasoning) combined with the negative result analysis.
